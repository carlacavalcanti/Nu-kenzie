# Nu Kenzie

Aplicação de controle financeiro desenvolvida em React.

## Funcionalidades

- Adicionar transações
- Exibir lista de transações
- Cálculo automático do valor total
- Separação entre entradas e saídas
- Interface componentizada com React
- Estilização com SCSS Modules

## Tecnologias

- React
- JavaScript
- SCSS Modules
- Vite

## Melhorias futuras

- Responsividade mobile
- Exclusão de transações
- Persistência de dados
